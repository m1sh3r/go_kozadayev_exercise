# Упражнения по Go

Этот проект содержит 10 заданий, реализованных на языке Go, с акцентом на gRPC, REST, PostgreSQL и конкурентную обработку.

## Общие требования
- Нет внешних зависимостей от Google API (ручная реализация REST).
- Чистая архитектура (domain/service/repository).
- Отсутствие комментариев в коде.
- Интеграция с PostgreSQL через `sqlc` и драйвер `pgx/v5`.
