# Задание 6: Личный кабинет владельца

## Реализация
- Разделение gRPC CRUD методов и сложного REST-агрегатора (Dashboard).
- Техника JOIN для получения списка машин и последней сервисной записи.

## Запуск
```bash
go run task6/main.go
```

## Примеры запросов
### Дашборд владельца
```bash
curl http://localhost:8080/v1/owners/1/dashboard
```
