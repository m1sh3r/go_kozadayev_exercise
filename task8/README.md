# Задание 8: Прокат автомобилей

## Реализация
- Работа с конкурентным доступом в PostgreSQL.
- Использование пессимистичной блокировки `FOR UPDATE` внутри транзакции.
- Проверка пересечения дат бронирования.

## Запуск
```bash
go run task8/main.go
```

## Примеры запросов
### Бронирование
```bash
curl -X POST http://localhost:8080/v1/bookings -d '{"car_id": 1, "start_date": 1715684400, "end_date": 1715770800}'
```
