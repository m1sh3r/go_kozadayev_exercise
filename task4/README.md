# Задание 4: Складской учет

## Реализация
- Асинхронное создание заказов.
- Использование **RabbitMQ** для передачи сообщений.
- Фоновый воркер для обработки заказов и смены их статуса.

## Запуск
```bash
go run task4/main.go
```

## Примеры запросов
### Создание заказа
```bash
curl -X POST http://localhost:8080/v1/orders -d '{"product_id": "laptop"}'
```
