# Задание 3: Конвейер автомобиля

## Реализация
- Атомарная сборка автомобиля из двигателя и КПП.
- Сложный JOIN для получения полной спецификации.
- Использование `pgx/v5` для работы с транзакциями.

## Запуск
```bash
go run task3/main.go
```

## Примеры запросов
### Сборка машины
```bash
curl -X POST http://localhost:8080/v1/assemble -d '{"car_id": 1, "engine_id": 1, "transmission_id": 1}'
```
### Спецификация машины
```bash
curl http://localhost:8080/v1/cars/1/spec
```
